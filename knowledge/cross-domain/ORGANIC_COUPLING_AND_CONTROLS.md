# DC//LAB Organic Coupling & Control Depth

This file records host feedback established after the first collision-first batch (011–015).

The technical diversity improved, but the work was still visually weak, under-parameterized and not organic enough. These are now durable creative constraints for substantial Gallery labs.

## 1. Control-depth rule

A substantial exploratory sketch should normally expose **6–9 meaningful artistic/systemic controls** when its mechanism genuinely supports them.

Three controls are not enough for a multi-system laboratory unless deliberate minimalism is itself the concept.

Good control dimensions change independent parts of the system, for example:

- coupling / permeability;
- threshold / phase boundary;
- memory / delay;
- repair / decay;
- population speed / appetite / birth rate;
- structural tension / damping;
- topology range;
- interaction radius or consequence strength;
- autonomous regime rate;
- material/render density.

Bad control depth is eight aliases of `more effect`, `more chaos`, or `more speed`.

The default state must remain strong without tuning.

## 2. Organic means local negotiation

If a work claims to be tissue-like, cellular, chemical, fluid, ecological or otherwise organic, individual pixels/cells/agents must not behave independently.

At least one state variable must move or propagate through **local relationships**:

- neighbour diffusion;
- excitation / refractory cycles;
- local pressure;
- attraction / repulsion;
- resource exchange;
- consumption;
- constraint transmission;
- phase propagation;
- graph connectivity;
- advection;
- delayed feedback.

Prefer more than one time scale:

`fast response + slower memory / repair / transport / fatigue`

A raster full of independently animated cells is not an organic system.

## 3. Coupling test

For every major subsystem, ask:

- What state does it read from another subsystem?
- What state does it write back?
- Does removing that exchange materially change the future behavior?

Examples:

`cell chemistry -> particle velocity -> particle density changes chemistry`

`agents -> constraint wear -> deformed constraint mesh redirects agents`

`node energy -> graph connectivity -> predators follow graph resources -> predation changes node energy`

One-way decoration is weaker than reciprocal coupling.

## 4. Raw does not mean ugly

Collision-first prototypes are allowed to be experimental, but a prototype promoted into the Gallery must pass a minimum visual gate:

- coherent default palette;
- intentional mass / void distribution;
- no project title/index/debug chrome in the canvas;
- frozen frames should not repeatedly look accidental or broken;
- spatial density must be controlled;
- visual hierarchy must survive autonomous motion;
- the composition should be worth watching before touching sliders.

Do not postpone every visual decision until a hypothetical later art-direction pass.

## 5. Pixel/cell quality gate

For cellular/raster labs, test the following before accepting the mechanism:

1. change one cell: can a consequence migrate to neighbours?
2. remove input: does the field keep negotiating its state?
3. does density create qualitatively different regimes, not only brighter pixels?
4. can local death/damage/resource depletion change another area later?
5. is there memory, refractory state, transport or repair beyond immediate interpolation?

If all answers are no, the cell system is probably decorative.

## 6. Parameter review

For a new 6–9 control sketch, controls should cover different layers where available:

- **material/state** — density, threshold, feed, appetite;
- **relationship** — coupling, network range, cohesion;
- **time** — damping, delay, decay, repair, refractory duration;
- **autonomy** — birth rate, regime rate, spontaneous seeding;
- **interaction** — seed radius, obstacle radius, damage strength;
- **render/composition** — only when it changes the artistic material, not to compensate for weak behavior.

At least half the controls should change the future evolution of the system, not only the current frame.

## 7. Batch rule

A five-work collision batch should vary both mechanism and control vocabulary.

Avoid five inspectors that all expose:

`SPEED / AMOUNT / SCALE / NOISE / COLOR`

Prefer inspectors that reveal the character of each mechanism:

`APPETITE / SCAR MEMORY / HYSTERESIS`

`CELL COUPLING / REFRACTORY TIME / EDGE FEED`

`MESH TENSION / LINK EROSION / LINK REPAIR`

The parameter names themselves should explain what kind of system the viewer/operator is manipulating.
