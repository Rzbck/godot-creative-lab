# Design + Typography Source Catalog

Curated external references for DC//LAB. This catalog mixes typography fundamentals, font engineering, graphic-design history, poster/editorial archives, professional identity systems, motion design and accessibility.

Use several sources for a project. Do not treat any single site as a universal rulebook.

## Typography fundamentals and type criticism

| Tier | Source | Domain | Why it matters |
|---|---|---|---|
| A | [Google Fonts Knowledge](https://fonts.google.com/knowledge) | typography fundamentals | Structured reference for type terminology, choosing/using type and digital typography. |
| A | [Thinking with Type](https://thinkingwithtype.com/) | typography / hierarchy / layout | Ellen Lupton's widely used framework for letters, text and grids. Use as conceptual reference; do not reproduce book content. |
| A | [Butterick's Practical Typography](https://practicaltypography.com/) | spacing / text composition | Concrete discussion of line length, leading, point size, tracking, hierarchy and professional text setting. |
| A | [Typotheque — Articles & Research](https://www.typotheque.com/stories) | typography research | Peter Biľak, Ellen Lupton and others on typography, reading, scripts, design and research. |
| B | [Typographica](https://typographica.org/) | type criticism | Long-running typeface reviews, type books and commentary. Useful for understanding formal qualities, not just font shopping. |
| B | [Typewolf Resources](https://www.typewolf.com/resources) | typography curation | Broad map of foundries, books, learning resources and contemporary web typography. |
| B | [Fontstand News](https://news.fontstand.com/) | contemporary type | Typeface reviews, foundry news, contemporary releases and professional type practice. |
| B | [Eye Magazine](https://www.eyemagazine.com/) | graphic design criticism | International review of graphic design and visual culture; valuable for historical and critical context. |
| B | [Slanted](https://www.slanted.de/) | typography / visual culture | International typography, graphic-design and visual-culture publishing with strong contemporary coverage. |

## How DC//LAB should use sources

- **Foundations/specs** define technical constraints and vocabulary.
- **Archives** reveal how strong designers solve hierarchy, rhythm, margins and composition in real work.
- **Studios** reveal how static identities become systems and motion languages.
- **Trend/discovery sites** help us see what is current, but should never dictate a sketch by themselves.
- **Books** supply deeper frameworks that websites often flatten into tips.

When borrowing an idea, record the principle in our atlas, not the surface appearance of the reference.
